🎙️ AmulyAI – Voice AI Assistant

AmulyAI is a voice-based conversational AI assistant that listens to user speech, processes it using AI, and responds back with natural spoken answers.

It enables real-time voice conversations with an AI system.

🚀 Features

🎤 Voice input (Speech-to-Text)

🧠 AI conversation processing

🔊 Spoken responses (Text-to-Speech)

⚡ Real-time voice interaction

🧩 Easy to extend and customize
